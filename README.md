# Neuro Shell: Enterprise AI Operating System (EOS)
### Shell plc — Fortune Global Enterprise AI Fabric

Neuro Shell is a high-fidelity, autonomous enterprise control tower designed to orchestrate Shell's strategic operating model. It integrates multi-domain intelligence across Industrial Ops, Global Logistics, Energy Trading, and Financial Strategy into a unified, agentic interface.

## 🚀 Deployment Hierarchy

To initialize the Neuro Shell EOS, the following services must be activated in sequence:

### 1. Unified Intelligence Backend (Port 5000)
The core data fabric and repository for the Shell Knowledge Graph (SKG).
```bash
cd backend
node server.js
```

### 2. Neural Reasoning Service (Port 5001)
Orchestrates APEX agent logic, real-time fire detection telemetry, and multi-agent negotiation.
```bash
cd ai-service
node server.js
```

### 3. Control Tower Frontend (Port 5173)
The strategic command-and-control dashboard.
```bash
cd frontend
npm install
npm run dev
```

## 🤖 APEX: Agentic Neural Intelligence
The platform features **APEX**, a distributed orchestrator powered by DeepSeek V3.
- **Cognitive Scope**: Autonomous navigation, cross-domain telemetry correlation, and real-time hazard mitigation.
- **Topology**: Visualized in the *Agentic Neural Topology* module, representing the live mesh of specialized agents (Commercial Sage, Guardian Eye, ITSM Dispatch).

## 📊 Core Strategic Domains
- **Control Tower**: The executive "God View" of global operations.
- **Asset Digital Twin**: High-fidelity 3D modeling of refining and manufacturing assets.
- **Industrial Ops & Refining**: Real-time QHSE and yield monitoring for global refineries.
- **Energy Trading & Risk**: Market volatility analysis and algorithmic risk mitigation.
- **Governance & Compliance**: Enterprise-wide neural registry and regulatory audit logs.

## 📁 System Architecture
- `frontend/`: React-Vite dashboard with Three.js, Framer Motion, and Lucide instrumentation.
- `backend/`: Node.js middleware managing the unified enterprise state (`unified_core.json`).
- `ai-service/`: Node.js microservice for agentic reasoning and safety detection.
