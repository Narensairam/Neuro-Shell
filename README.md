Neuro Shell is a high-fidelity, autonomous enterprise control tower designed to orchestrate Shell's strategic operating model. It integrates multi-domain intelligence across Industrial Ops, Global Logistics, Energy Trading, and Financial Strategy into a unified, agentic interface.

## 🚀 Strategic Transformation Waves

The Neuro Shell platform is deployed in alignment with the SHL-EOS-2026 Strategic Blueprint:

- **Wave 1: Digital Foundation (Active)** — Consolidation of multi-domain telemetry and SKG (Shell Knowledge Graph) integration. Dashboard maturity level: 4 (Optimal).
- **Wave 2: Agentic Orchestration (In-Flight)** — Deployment of APEX and specialized autonomous agents (Commercial Sage, Guardian Eye) for closed-loop decision making.
- **Wave 3: Cognitive Autonomy (Roadmap)** — Full-scale predictive refining and algorithmic market response with zero-latency human-in-the-loop oversight.

## 🛠 Deployment Hierarchy

To initialize the Neuro Shell EOS, the following services must be activated in sequence:

### 1. Unified Intelligence Backend (Port 5000)
The core data fabric and repository for the Shell Knowledge Graph (SKG).
```bash
cd backend
node server.js
```

### 2. Neural Reasoning Service (Port 5001)
Orchestrates APEX agent logic, real-time fire detection telemetry, and multi-agent negotiation.
```bash
cd ai-service
node server.js
```

### 3. Control Tower Frontend (Port 5173)
The strategic command-and-control dashboard.
```bash
cd frontend
npm install
npm run dev
```

## 🤖 APEX: Agentic Neural Intelligence
The platform features **APEX**, a distributed orchestrator powered by DeepSeek V3.
- **Cognitive Scope**: Autonomous navigation, cross-domain telemetry correlation, and real-time hazard mitigation.
- **Agentic Topology**: A live mesh of specialized agents including:
  - **Commercial Sage**: Algorithmic energy trading and risk mitigation.
  - **Guardian Eye**: Real-time CV-based site safety and fire detection.
  - **ITSM Dispatcher**: Autonomous resolution of platform operational debt.

## 📊 Core Strategic Domains
- **Control Tower**: The executive "God View" of global enterprise health.
- **Asset Digital Twin**: High-fidelity 3D modeling of refining assets with live telemetry.
- **Industrial Ops & Refining**: Real-time QHSE, yield monitoring, and site-specific auditing.
- **Energy Trading & Risk**: Market volatility analysis and contract automated reasoning.
- **Governance & Compliance**: Multi-domain neural registry and enterprise regulatory audit logs.

## 📁 System Architecture
- `frontend/`: React-Vite dashboard using Three.js (Digital Twin), React Flow (Topology), and Recharts (KPIs).
- `backend/`: Node.js middleware managing the global unified state (`unified_core.json`).
- `ai-service/`: Node.js/Python microservice for agentic reasoning and distributed telemetry.
